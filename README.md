# Loan Charge-Off Risk Analysis

## Project Overview
This project analyzes loan charge-offs associated with deceased members within a credit union environment. The goal was to identify financial risk patterns, evaluate the impact of insurance coverage, and provide recommendations to reduce losses.

## Tools Used
- SQL
- Power BI
- Microsoft Word

## Key Insights
- Deceased members accounted for approximately 10% of total charge-off losses.
- Approximately 86% of losses were associated with uninsured loans.
- Personal loans represented the highest loss segment.

## Recommendations
- Increase adoption of loan protection insurance.
- Strengthen underwriting controls for unsecured loans.
- Improve monitoring of high-risk accounts.
